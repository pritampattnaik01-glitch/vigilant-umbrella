# Prakriti Soaps — Ecommerce Starter

A responsive soap-store website inspired by the uploaded reference: cream/peach palette, centered logo, category navigation, product cards, cart drawer and checkout.

## Run locally

1. Install Node.js.
2. Open a terminal in this folder.
3. Run `npm install`.
4. Copy `.env.example` to `.env`.
5. Add your SMTP/Gmail credentials.
6. Run `npm start`.
7. Open http://localhost:3000

Orders are sent to `pritampattnaik01@gmail.com`.

### Gmail setup
Use a Google App Password for `SMTP_PASS`; do not put your normal Gmail password in the project.

## Important
The screenshot's brand/logo/assets are used only as a visual reference. Replace the sample brand name and product content with your own branding before launch.
